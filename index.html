Install Sailfish OS on the Sony Xperia 10 VI

This page installs the Sailfish OS community port for the Xperia 10 VI (pdx246) from your browser. It does what flash.sh in the image zip does, without installing anything on your computer.

Unofficial community port, not affiliated with Jolla or Sony. Prototype: tested once on a real phone, with Chrome on Linux.

Simulation. A simulated phone stands in for USB; nothing reaches a real device. Phone: ?.

Before you start

  • Installing erases all data on the phone (apps, photos, files). Back up what you want to keep.
  • Charge the phone to at least 50 %.

If the phone runs Sony's Android

  1. Install Sony's newest software update (Settings, System, Software update). After the bootloader is unlocked, Sony offers no more updates, and LineageOS 23.2 needs firmware 70.2 or newer.
  2. Turn on OEM unlocking: in Settings, About phone, tap Build number seven times; then turn on OEM unlocking in Settings, System, Developer options.
  3. Get Sony's unlock code: dial *#06# for the phone's IMEI (it has two: use IMEI 1), and enter it for the Xperia 10 VI on Sony's unlock page. The code has 16 characters.

Unlocking the bootloader erases the phone and removes Sony's DRM keys for good: Sony warns that some camera functions and protected content may stop working, and that the warranty may be void.

If the phone runs LineageOS or Sailfish OS

  • The bootloader is unlocked already.
  • To install Sailfish OS over LineageOS, the phone must run LineageOS 23.2 for pdx246, release v23.2-20260924, installed on slot a and started once to its home screen (wait a minute there, so that its setup completes).
  • Keep that LineageOS release's images (boot.img, vendor_boot.img, dtbo.img, vendor_dlkm.img, recovery.img). They are the only way back, and installing again over Sailfish OS needs them.

The full instructions, including installing without this page, are in INSTALL.md.

Your computer

Use Chrome, Chromium, Microsoft Edge or Brave on Windows, macOS, Linux or ChromeOS. Firefox and Safari cannot talk to USB devices from a web page. Plug the phone directly into the computer, not through a hub, a docking station or a virtual machine.

Linux

The browser needs permission to open the phone. Distributions with systemd 258 or newer (Ubuntu 26.04, for example) give it automatically. Others need udev rules: many have a package with them (for example android-udev-rules); otherwise create them once: 

sudo tee /etc/udev/rules.d/51-xperia-fastboot.rules <<'EOF'
SUBSYSTEM=="usb", ATTR{idVendor}=="0fce", ATTR{idProduct}=="0dde", TAG+="uaccess"
SUBSYSTEM=="usb", ATTR{idVendor}=="18d1", ATTR{idProduct}=="4ee0", TAG+="uaccess"
EOF
sudo udevadm control --reload-rules

Then plug the phone in again. If the browser still cannot open it, the firmware update service may have taken it: sudo systemctl stop fwupd (until the next restart).

Ubuntu's Chromium is a snap, which may open USB devices only after sudo snap connect chromium:raw-usb; restart Chromium afterwards.

Windows

Windows needs a driver for the phone's fastboot mode. Install Google's USB driver, then in the Device Manager choose the phone (it may appear as an unknown device or as Android), Update driver, Browse my computer, Let me pick, Have disk, select android_winusb.inf and Android Bootloader Interface. Not yet tested with this page.

macOS and ChromeOS

Nothing to install.

Read-only check

This page is in read-only mode. It asks the phone only for its model, firmware versions and lock state, the questions flash.sh asks first, and refuses to send anything else: it cannot change or restart the phone. Connect the phone below.

1 What do you want to do?

Action

2 Choose the files

Sailfish_OS-…-pdx246-….zip from the releases page. Do not unpack it; this page reads it as it is and checks it first.

Choose all of them at once: , from the LineageOS release v23.2-20260924.

    lineage-23.2-20260924-UNOFFICIAL-pdx246.zip from the LineageOS release v23.2-20260924 (not a 24.0 release). The page unpacks and checks all of it first, which takes a few minutes.

    Needed only while the bootloader is locked; the page shows the lock state after Connect.

    3 Connect the phone

    1. Switch the phone off.
    2. Hold volume up and plug in the USB cable. The screen stays dark apart from a small mark in its top left corner: the phone is in fastboot mode.
    3. Click Connect and choose the phone in the list the browser shows.

    4 Install

    This takes about ten minutes. Do not unplug the phone or close this page. The phone restarts twice during the installation; the first time it restarts into fastbootd, the browser asks you to choose the phone again.

      5 Done

      The first start

      • The first start takes longer. After the language and the terms, the phone encrypts its data; this needs a charger or more than 30 % battery.
      • It then asks for a security code, which every start asks for. Choose one you will remember: a forgotten code cannot be reset, the only way back is installing again, which erases all data.
      • Mobile data and calls over VoLTE work after you enable mobile data in Settings, Mobile network.
